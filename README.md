# HR Analytics Dashboard

## Project Overview
This project analyzes employee attrition using Power BI to identify trends and provide actionable HR insights.

## Tool Used
- Power BI

## Dashboard Preview

![Dashboard](dashboard.png)

## Key Insights
- Overall Attrition Rate: 16.1%
- Laboratory Technicians have the highest attrition.
- Employees aged 26–35 show the highest attrition.
- Employees earning up to 5K have the highest attrition.

## Features
- Department slicer
- Interactive charts
- KPI cards
- Cross-filtering
- DAX measures
